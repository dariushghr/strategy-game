# بازی استراتژیک (Java Swing)

بازی نوبتی روی نقشهٔ هگز که با Java 21 و Swing اجرا می‌شود. منطق دامنه از UI جداست؛ ذخیره و بارگذاری فقط وضعیت بازی را می‌نویسند، نه پنجره‌ها.

## اجرا

پیش‌نیاز: JDK 21 و Maven.

```bash
mvn -q compile
mvn -q exec:java
```

یا بعد از بسته‌بندی:

```bash
mvn -q package
java -jar target/strategy-game.jar
```

## ذخیره و بارگذاری

- از منوی اصلی: **بارگذاری**
- داخل بازی: دکمهٔ **ذخیره** در نوار بالا (ذخیرهٔ دستی یا بارگذاری)
- سه اسلات دستی و یک اسلات **ذخیرهٔ خودکار** جدا
- فایل‌ها در `~/.strategygame/saves/` نوشته می‌شوند و اسلات خودکار اسلات دستی را عوض نمی‌کند
- ذخیرهٔ خودکار بعد از پایان کامل نوبت است؛ اگر شکست بخورد بازی متوقف نمی‌شود
- در حین حرکت، پایان نوبت یا انیمیشن بلای طبیعی ذخیره قفل است

## تست رفت‌وبرگشت ذخیره (بدون UI)

```bash
mvn -q exec:java -Dexec.mainClass=org.strategygame.save.SaveRoundTrip
```

باید `OK` چاپ شود. این تست seed، نوبت، تعداد یونیت/ساختمان/قبیله و دنبالهٔ RNG را بعد از Load مقایسه می‌کند.

## ساختار کوتاه

- `model` وضعیت بازی
- `service` قوانین نوبت، نبرد، تجارت، قبیله و بلایا
- `controller` ورودی بازیکن
- `view` Swing
- `save` JSON نسخه‌دار و نوشتن اتمیک فایل
